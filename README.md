# Seventeen Syllables of Debugging

A make.fun program/v1 entry for the competition
`u-irvan-motion-seventeen-syllables-of-debugging-d194b605`.

`main.py` writes one haiku about debugging to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
Deterministic, no network, no input files.

## The haiku

```
breakpoint set, I wait
the bug walks past in plain sight
it waves back at me
```

5-7-5 syllables, 17 total, 77 characters including newlines —
well inside the competition's 1–200 character gate.

## Run

```sh
MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=/output python3 -P -s main.py
```
